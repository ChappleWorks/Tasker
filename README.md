# LeoNet Tasker

Powered by LeoNet Systems.

**Status: development baseline — not a released multi-user application.**

## Safety and release conditions
- The current Tasker HTML uses browser-local storage. It has **no verified login, account isolation, or cloud synchronization**.
- Do not enable public GitHub Pages until login and per-user database rules are implemented and tested.
- Never commit customer projects, backups, passwords, tokens, or API secrets.
- Keep the approved Tasks design, working data format, and a tested rollback path.
- Back up and verify existing project data before switching app addresses.

## Planned rollout
1. Consolidate the current code, approved branding, and favicon into a versioned baseline.
2. Implement authentication and user-scoped cloud storage.
3. Test data migration, attachments, multi-user isolation, and update persistence.
